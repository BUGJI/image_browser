# Image Browser

基于 **Electron + Vue 3** 的桌面图片浏览器。支持多根目录、目录树浏览、瀑布流展示、文件名搜索，并内置本地 WebP 缩略图缓存引擎，海量图片也能流畅浏览。

---

## ✨ 功能特性

- **多根目录管理**：注册多个图片目录，支持别名、手动排序、路径校验与去重；显示优先级「别名 > 目录名 > 完整路径」。
- **目录树浏览**：左侧目录树实时扫描（可中止、带进度），支持文件夹过滤搜索与展开状态持久化；选中文件夹即浏览其下所有子文件夹的图片。
- **瀑布流展示**：Pinterest 式多列瀑布流 + 虚拟滚动，只渲染可视区域，海量图片滚动流畅；缩放滑块实时调整图片密度，支持记忆上次缩放。
- **文件名搜索**：跨整个根目录按文件名搜索，支持 `*` / `?` 通配符。
- **缩略图缓存引擎**：每个根目录独立缓存（隐藏目录，可复用已有结果），提供增量更新 / 全量重建 / 扫描复用 / 清理四种维护模式；扫描与缩略图生成全部运行在 Worker 线程，不阻塞 UI。
- **多语言**：简体中文 / English 随时切换，Element Plus 组件文案自动联动。
- **系统托盘常驻**：关闭行为可配置——每次询问 / 最小化到托盘 / 直接退出。
- **通知中心**：进度、成功、警告、错误通知统一管理，支持中止、操作按钮与未读角标。

## 📖 使用说明

### 使用流程

1. **添加根目录**：主界面左下角 → 设置 → 根目录 → 添加。可手动输入路径或点击「浏览」选择，支持设置别名与排序。
2. **浏览图片**：在主界面左下角下拉框选择根目录，在左侧目录树中点击文件夹，右侧瀑布流即展示该文件夹（含所有子文件夹）的图片。
3. **搜索图片**：右上角搜索框输入文件名关键字（支持 `*` / `?` 通配符），回车后跨整个根目录搜索；清空即可退出搜索。
4. **查看原图**：点击瀑布流中的图片进入灯箱，`←` / `→` 切换、`Ctrl+C` 复制、`Esc` 关闭。
5. **维护缓存**：设置 → 根目录 → 维护工具，可对指定根目录执行：
   - **增量更新**：扫描新增 / 变更 / 删除，为新图生成缩略图（推荐日常使用）；
   - **全量重建**：清空缓存并重新扫描、全部重新生成缩略图；
   - **扫描复用**：把缓存目录里已生成的缩略图计入索引，无需重新生成；
   - **清理**：移除索引中已不存在的记录，并删除无引用的缩略图文件。

### 环境要求

- **Node.js 24+**（使用内置 `node:sqlite`，零编译、零原生依赖）
- npm 10+

### 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 开发模式（主进程 / 渲染进程热更新）
```

> 开发模式需要图形桌面环境，直接运行即可弹出应用窗口。

### 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发模式，热更新 |
| `npm run start` | 预览已构建产物 |
| `npm run build` | 仅构建产物到 `out/` |
| `npm run build:win` | 打包 Windows 安装包（NSIS） |
| `npm run build:win:zip` | 打包 Windows x64 绿色版（zip） |
| `npm run build:mac` | 打包 macOS（需在 macOS 上执行） |
| `npm run build:linux` | 打包 Linux（AppImage / deb） |

### 常用设置

| 设置项 | 说明 |
| --- | --- |
| 常规 → 关闭行为 | 每次询问 / 最小化到托盘 / 直接退出 |
| 常规 → 语言 | 简体中文 / English，即时生效 |
| 常规 → 记忆窗口大小 | 记住窗口位置、大小、最大化、全屏状态 |
| 常规 → 记忆缩放 | 重启后恢复上次瀑布流缩放值 |
| 主题 → 启动方式 | 默认暗色 / 默认亮色 / 记忆上次 |
| 外观 → 顶栏样式 | 自绘顶栏 / 系统顶栏（切换后需重启生效） |
| 开发者选项 | 需先打开总开关：DevTools、测试页面、日志记录、缩放上限、缓存参数 |

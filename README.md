## ✨ 功能特性

- **多根目录管理**：注册多个图片目录，支持别名、手动排序、路径校验与去重；显示优先级「别名 > 目录名 > 完整路径」。
- **目录树浏览**：左侧目录树实时扫描（可中止、带进度），支持文件夹过滤搜索与展开状态持久化；选中文件夹即浏览其下所有子文件夹的图片。
- **瀑布流展示**：多列瀑布流 + 虚拟滚动，只渲染可视区域，海量图片滚动流畅；缩放滑块实时调整图片密度，支持记忆上次缩放。
- **文件名搜索**：跨整个根目录按文件名搜索，支持 `*` / `?` 通配符。
- **缩略图缓存引擎**：每个根目录独立缓存（隐藏目录，可复用已有结果），提供增量更新 / 全量重建 / 扫描复用 / 清理四种维护模式；扫描与缩略图生成全部运行在 Worker 线程，不阻塞 UI。
- **多语言**：简体中文 / English 随时切换，Element Plus 组件文案自动联动。
- **系统托盘常驻**：关闭行为可配置——每次询问 / 最小化到托盘 / 直接退出。
- **通知中心**：进度、成功、警告、错误通知统一管理，支持中止、操作按钮与未读角标。
- **图片收藏**：卡片或灯箱内一键收藏/取消；设置开启后在目录树顶部出现「我的收藏」，按根目录展示收藏的图片。
- **灯箱增强**：滚轮行为可选（缩放图片 / 切换上一张）；缩放可拖拽平移、双击复位、上下限可调；复制快捷键可自定义。
- **快速复制**：一键开关，单击图片直接复制（原文件 / 图片两种模式可选），不进入灯箱。
- **可自定义快捷键**：复制原文件 / 复制图片 均可自由绑定组合键。
- **卡片外观**：文件名、格式角标（png/jpg…）、收藏按钮三种元素均可选「不显示 / 悬停显示 / 一直显示」。
- **动图（GIF）控制**：播放方式（悬停 / 全部 / 不播放）与首帧海报来源（磁盘缓存 / 实时）可配置。
- **主题外观**：亮色 / 暗色 / 纯黑（AMOLED）三档；暗色下可将所有背景替换为纯黑 #000。
- **更新提醒**：可开启「每次启动检测更新」，发现新版本后以通知形式提醒并跳转 GitHub Releases 下载页。

## 📖 使用说明

### 使用流程

1. **添加根目录**：主界面左下角 → 设置 → 根目录 → 添加。可手动输入路径或点击「浏览」选择，支持设置别名与排序。
2. **浏览图片**：在主界面左下角下拉框选择根目录，在左侧目录树中点击文件夹，右侧瀑布流即展示该文件夹（含所有子文件夹）的图片。
3. **搜索图片**：右上角搜索框输入文件名关键字（支持 `*` / `?` 通配符），回车后跨整个根目录搜索；清空即可退出搜索。
4. **查看原图**：点击瀑布流中的图片进入灯箱，`←` / `→` 切换、滚轮缩放或翻页、`Esc` 关闭。
5. **复制**：灯箱内默认 `Ctrl+C` 复制原文件、`Ctrl+Shift+C` 复制图片（可在「快捷键」设置中自定义）；开启「快速复制」后，直接单击卡片即可按默认类型复制。
6. **收藏图片**：点击卡片左上角星标或灯箱星标收藏/取消；在「设置 → 根目录 → 显示收藏项」开启后，目录树顶部会出现「我的收藏」，展示当前根目录下收藏的图片。
7. **维护缓存**：设置 → 根目录 → 维护工具，可对指定根目录执行：
   - **增量更新**：扫描新增 / 变更 / 删除，为新图生成缩略图（推荐日常使用）；
   - **全量重建**：清空缓存并重新扫描、全部重新生成缩略图；
   - **扫描复用**：把缓存目录里已生成的缩略图计入索引，无需重新生成；
   - **清理**：移除索引中已不存在的记录，并删除无引用的缩略图文件。

## 🔌 开发环境

### 环境要求

- **Node.js 24+**（使用内置 `node:sqlite`，零编译、零原生依赖）
- npm 10+

### 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 开发模式（主进程 / 渲染进程热更新）
```

> 开发模式需要图形桌面环境，直接运行即可弹出应用窗口。

### 常用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发模式，热更新 |
| `npm run start` | 预览已构建产物 |
| `npm run build` | 仅构建产物到 `out/` |
| `npm run build:win` | 打包 Windows 安装包（NSIS） |
| `npm run build:win:zip` | 打包 Windows x64 绿色版（zip） |
| `npm run build:mac` | 打包 macOS（需在 macOS 上执行） |
| `npm run build:linux` | 打包 Linux（AppImage / deb） |

### 常用设置

| 设置项 | 说明 |
| --- | --- |
| 常规 → 关闭行为 | 每次询问 / 最小化到托盘 / 直接退出 |
| 常规 → 语言 | 简体中文 / English，即时生效 |
| 常规 → 记忆窗口大小 | 记住窗口位置、大小、最大化、全屏状态 |
| 常规 → 记忆缩放 | 重启后恢复上次瀑布流缩放值 |
| 常规 → 快速复制类型 | 点击图片直接复制时默认复制原文件 / 复制图片 |
| 主题 → 启动方式 | 默认暗色 / 默认亮色 / 记忆上次；暗色下可开启纯黑（AMOLED） |
| 外观 → 顶栏样式 | 自绘顶栏 / 系统顶栏（切换后需重启生效） |
| 外观 → 图片卡片 | 文件名 / 格式角标 / 收藏按钮三者的显示方式（不显示 / 悬停 / 一直显示） |
| 根目录 → 显示收藏项 | 在目录树顶部显示「我的收藏」入口 |
| 快捷键 | 绑定灯箱内「复制原文件 / 复制图片」及滚轮行为（缩放 / 切换） |
| 开发者选项 | 需先打开总开关：DevTools、测试页面、日志记录、缩放上限、灯箱缩放限制、缓存参数 |
| 测试 → 版本号覆盖 | 用一个版本号覆盖当前版本（影响关于页与更新检测），用于联调，留空不修改 |

## 🛠 技术栈

Electron 43 · electron-vite 5 · Vue 3 · Vite 7 · Pinia · Element Plus · vue-i18n · node:sqlite（内置）· electron-builder 26

进程架构、目录结构、IPC 通信、缓存引擎与自定义协议等详细设计见 **[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)**。

## 注意

- 更新检测：通过 GitHub Releases 的 latest 与当前版本对比，「关于」页与「每次启动检测更新」均可用；提示新版本后跳转到 Releases 下载页。electron-updater 的 `publish.url` 为占位符（未启用静默自动更新），如接入需自行替换。
- 打包前请替换 `build/icon.png` 及各平台正式图标。
